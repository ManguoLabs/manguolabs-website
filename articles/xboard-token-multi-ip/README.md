# 一个 XBoard Token 同时出现多个 IP，一定是订阅共享吗？

关键词：Token多IP、一个Token多个IP、XBoard Token多IP、订阅共享、真实连接IP、XBoard、Evidence

Token 多 IP 并不能直接等同于多人共享。家庭网络、运营商 NAT、移动网络、旅行和代理软件都会影响判断。

## 为什么单看 IP 数量容易误判

同一用户可能在家庭宽带、移动网络、公司网络之间切换，也可能通过代理软件访问订阅。因此“Token 出现多个 IP”更适合作为调查线索，而不是直接结论。

## 更可靠的判断方式

可以把 Token、订阅请求时间、登录 IP、注册 IP、UA 指纹和真实连接 IP 放在同一时间线上，再结合异常频率和地区变化分析。

## 什么时候需要系统化审计

当可疑账号数量增加、需要持续关联 Token、登录、订阅请求与连接证据，或人工表格已无法稳定复核时，才需要系统化工具；单次多 IP 仍不能直接判定违规。
