## 登录IP和订阅IP关联的核心逻辑

登录IP是用户在面板完成身份验证时产生的网络地址，订阅IP是客户端向订阅接口请求节点列表时的地址。关联的目标是判断同一Token是否被多个物理位置或真实用户使用。

XBoard默认记录登录IP与订阅请求IP，但两者不会自动关联。当同一Token在短时间内出现地理位置差异明显的登录IP（如北京）和订阅IP（如广州），或同一订阅IP被多个不同账号Token访问时，可能存在订阅共享或Token泄露。

判断需要结合时间窗口、IP地理位置、Token历史行为和真实连接IP。单一IP线索容易因NAT、移动网络或代理产生误判，需要多维证据支撑风险评分。

## 如何从数据库提取登录与订阅的IP关联证据

进入XBoard数据库，查询v2_user表中的token字段和last_login_ip字段，获取用户最近一次登录的IP地址。

然后在Nginx或Web服务器日志中查找包含该Token的订阅请求，格式通常为GET /api/v1/client/subscribe?token=xxx。提取该请求的真实客户端IP，注意需要从X-Forwarded-For或X-Real-IP头中取得，而非直接的remote_addr。

将同一Token的登录IP、订阅请求IP和日志时间戳整理成时间序列，对比IP归属地和出现时间间隔。若同一Token在5分钟内出现跨国或跨省的IP切换，或同一订阅IP短时间内请求多个不同Token，需要进一步关联真实连接IP验证是否为共享行为。

## 可执行的三步关联检查流程

第一步，导出最近7天的登录记录：执行 SELECT id, email, token, last_login_ip, updated_at FROM v2_user WHERE updated_at >= DATE_SUB(NOW(), INTERVAL 7 DAY)，得到用户最近登录IP清单。

第二步，从Nginx访问日志中提取订阅请求IP：运行 grep "/api/v1/client/subscribe" /var/log/nginx/access.log | awk '{print $1, $7}' 提取IP和Token参数，使用脚本解析URL参数中的token值并统计每个Token对应的订阅IP列表。

第三步，交叉比对并标记异常：将登录IP与订阅IP按Token分组，计算每个Token的唯一IP数量和地理位置跨度。若同一Token关联IP数超过3个且分布在不同城市，或同一IP在1小时内请求超过5个不同Token，输出到可疑账号列表并人工复核真实连接IP和使用场景。

## NAT、移动网络与旅行场景的误判边界

同一 IP 出现多个 Token 或订阅请求并不必然代表共享。家庭宽带 NAT、公司网络、移动网络 CGNAT、酒店 Wi-Fi、机场公共网络和旅行中的临时网络都会让不相关的用户共享出口 IP。移动运营商的 IP 池轮换可能让同一用户在数小时内出现十几个不同 IP，但这些 IP 同时被其他用户使用。

单纯依赖 IP 重叠会产生大量误判。真实的风险需要结合 Token 与 IP 的时间分布、User-Agent 一致性、订阅频率和 Soga 真实连接 IP 的稳定性。如果某个 IP 在 5 分钟内出现 8 个不同 Token 的订阅请求且 UA 各不相同，风险显著高于一天内零星出现 3 个 Token 且 UA 相同的情况。Manguo Labs XBoard 订阅安全审计系统在计算风险评分时会区分这些场景，并标记"需人工复核"而非直接封禁。

## 常见问题

### 登录 IP 和订阅 IP 不一致就能判断是账号共享吗？

不能。移动网络切换基站、家庭和公司 NAT 出口不同、使用 VPN 或代理、多设备登录都会造成 IP 不一致。单次不一致只是线索，需要结合时间窗口、地理跨度、UA 和历史关系综合判断，并通过人工复核确认真实场景后再决定是否封禁。

### 同一个 Token 出现多个订阅 IP 是什么情况？

可能是用户在多个设备或网络环境下更新订阅，也可能是 Token 泄露或共享给他人。判断方法是检查这些 IP 的时间间隔、地理位置和 UA：短时间内跨地区、UA 差异大、IP 段归属不同运营商或国家时，共享风险较高；同城或同运营商、UA 一致时更可能是正常多设备使用。

### Soga 真实连接 IP 和订阅 IP 有什么区别？

订阅 IP 是用户客户端请求订阅链接时的来源 IP，Soga 真实连接 IP 是用户客户端连接节点时记录的真实 IP。如果用户用代理请求订阅但直连节点，或者反过来，两者会不同。关联这两类 IP 可以发现代理行为或异常路径，但也需要考虑用户切换网络的正常场景。

### 账号关联可以追踪到几层传播关系？

理论上可以追踪无限层，但实际分析中一般追踪到 3-8 层已足够覆盖绝大多数传播链。层数越深，噪音越多，需要设置时间窗口、关联强度阈值和传播路径过滤规则，避免把无关账号误纳入关联网络。人工复核是最终确认的必要步骤。

### Manguo Labs XBoard 订阅安全审计系统能自动封禁可疑账号吗？

不能。系统提供风险评分、关联图谱和异常证据，但不会自动封禁。风险概率不是封禁唯一依据，运营者需要结合业务场景、用户沟通和历史记录进行人工复核，确认真实情况后再决定封禁、警告或放行，避免误伤正常用户。
