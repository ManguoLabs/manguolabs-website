支持哪些节点来源

  • 本地 JSON 节点配置
  • 远程 API 节点来源
  • 多个 Clash YAML 订阅地址
  • 自动采集公开线路工具

不同来源可统一处理后，根据 XBoard 用户状态和权限组动态注入订阅。

核心能力

  • 支持 Shadowsocks、Trojan、VLESS、VMess、Hysteria2、AnyTLS、Mieru 等协议数据处理
  • 支持 VLESS ECH 等扩展参数
  • 支持自动识别节点国家或地区并重命名
  • 支持过滤无法识别地区的节点
  • 支持按 XBoard 权限组控制节点可见范围
  • 支持订阅缓存，降低远程订阅源请求压力

适用场景

  • 需要临时增加扩展线路
  • 需要同时维护多个 Clash / API 节点来源
  • 需要按套餐或权限组下发不同节点池
  • 希望降低人工整理、命名和筛选节点的工作量
第三方节点的可用性、速度、稳定性和流量限制由实际节点来源决定；扩展工具负责读取、处理、筛选与下发。

常见问题

XBoard 可以直接导入 Clash 订阅吗？

支持填写多个 Clash YAML 订阅地址并统一处理节点数据后注入 XBoard 用户订阅。

能按不同套餐下发不同扩展节点吗？

可以通过 XBoard 权限组控制扩展节点可见范围。

支持哪些常见协议？

支持 Shadowsocks、Trojan、VLESS、VMess、Hysteria2、AnyTLS、Mieru 等节点数据处理。

免费节点的稳定性由谁保证？

节点可用性和稳定性取决于节点来源，本工具负责采集、处理、过滤、命名与下发。
